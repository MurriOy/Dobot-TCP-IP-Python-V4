# Goal
Having a working demo that combines vision server with analysis and access to camera with Dobot CR3SA robot movements.

Code for robot control is the Dobot SDK in the root of current directory

Most scripts that are being actively worked on are under ./examples/ directory

# Library for coordinate frame transformations
`roboticstoolbox-python`

# testing code
Use `uv run [your_script]`

# external interface to vision server
There's a client available at external_libraries/demo_api_client

Rest of the code and documentation of vision server available in:
`../riact_vision_api/`
`../riact_vision_api/doc`
